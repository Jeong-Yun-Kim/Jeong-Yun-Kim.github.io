# 김정윤 포트폴리오

Robotics · Autonomous Driving · Backend

로봇 제어, 자율주행 시뮬레이션, 서버 개발 프로젝트와 활동을 정리한 개인 포트폴리오.

**[포트폴리오 보기 →](https://jeong-yun-kim.github.io/)**

## 주요 내용

- 분야별 프로젝트 필터와 상세 보기
- 개발 과정·검증 결과·후속 과제를 정리한 프로젝트 기록
- 기술, 활동, 수상 내역과 개발 아카이브
- 인쇄 가능한 이력서와 이메일 연락처

## 기술

HTML · CSS · JavaScript · GitHub Pages

프레임워크와 외부 CDN 없이 동작하는 정적 페이지. 공통 화면과 JSON 자료를 Python 표준 라이브러리로 조합하며, 배포 결과물은 순수 HTML이다.

## 관리 문서

콘텐츠 수정과 배포 방법은 [포트폴리오 관리](docs/maintenance.md)에 정리되어 있습니다.

## 라이선스

사이트 구현 코드는 MIT 라이선스. 개인 이력·프로젝트 설명·사진·시연 자료는 MIT 적용 대상에서 제외하며 권리는 원저작자에게 있다. 공개 GitHub 프로젝트의 소스 코드는 이 저장소로 복제하지 않았다.
