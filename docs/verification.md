# HTML 포트폴리오 검증 기록

검증일: 2026-10-27

## 자동 검사

- `npm run verify` 통과: JavaScript 구문, Python 표준 라이브러리 기반 HTML 생성, HTML 메타데이터·제목·내부 경로·앵커 검사.
- HTML 11개, 내부 참조 247개, 대표 프로젝트 기록 4개 확인.
- 기존 개요·개발 배경·평가·결과·제한 사항 보존 검사.
- 주요 상세 주소, 소개, 이력서, 404, sitemap 및 robots 경로 유지.

## 브라우저 검사

- 데스크톱 1363px 첫 화면 렌더링과 수평 넘침 없음 확인.
- 360px, 768px iframe 뷰포트에서 메인 레이아웃과 수평 넘침 없음 확인.
- 360px 상세 페이지와 이력서, 1440px 이력서 수평 넘침 없음 확인.
- 모바일 메뉴 열기·메뉴 선택 후 닫기 확인.
- 자율주행 필터에서 1/4 표시 및 해당 카드만 표시 확인.
- 프로젝트 상세 dialog, 다음 프로젝트 이동, Esc 닫기, 열었던 링크로 포커스 복귀 확인.
- 미리보기 HTTP 환경에서 클립보드 사용 불가 시 주소 선택·직접 복사 안내 확인. HTTPS에서의 자동 복사는 별도 확인 대상.

## 범위

브라우저 검사 대상은 이번 포트폴리오 UI이며, 링크된 로봇 프로젝트의 시험을 재실행한 기록이 아니다. 프로젝트 수치는 각 프로젝트의 원래 기록을 따른다. PDF 인쇄 스타일은 구현했으며 실제 프린터와 각 브라우저별 출력은 확인하지 않았다.
